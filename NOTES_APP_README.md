# 📝 Note Taking App

A productivity-focused note-taking application with rich text editing, organization, and synchronization across devices.

## 🎯 Features

- 📝 Rich text editor with formatting
- 📂 Folder and tag organization
- 🔍 Full-text search
- 🔐 Encrypted notes for privacy
- ☁️ Cloud sync across devices
- 📱 Responsive mobile design
- 📌 Pin important notes
- 🎨 Customizable themes
- 📊 Note statistics and insights
- 🗑️ Trash and recovery

## 🛠️ Tech Stack

- **Frontend**: React, Quill Editor
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Storage**: AWS S3
- **Authentication**: OAuth 2.0
- **Styling**: Sass, CSS Grid

## 📦 Installation

```bash
git clone https://github.com/ashu-jha8797/note-app.git
cd note-app

npm install
npm start
```

## 🎨 Features Overview

### Note Management
- Create unlimited notes
- Automatic saving (every 2 seconds)
- Rich text formatting
- Code snippet support
- Checkbox lists

### Organization
- Create custom folders
- Tag-based organization
- Smart collections
- Search history
- Filter options

### Collaboration
- Share notes with others
- Collaborative editing
- Comments and mentions
- Version history
- Access control
