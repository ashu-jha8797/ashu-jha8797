# 🎮 Portfolio Showcase

A modern portfolio website showcasing all projects with interactive demos, GitHub links, and contact information.

## 🎯 Features

- 🎨 Modern responsive design
- 📱 Mobile-first approach
- ⚡ Fast loading with optimization
- 🎬 Smooth animations
- 🔗 Direct GitHub integration
- 📧 Contact form with validation
- 🌙 Dark/Light theme toggle
- 📊 Project statistics
- 💼 Professional styling
- 🚀 SEO optimized

## 🛠️ Tech Stack

- **Frontend**: React, Gatsby
- **Styling**: Tailwind CSS, SCSS
- **Animation**: Framer Motion
- **Forms**: React Hook Form
- **Hosting**: Vercel, Netlify
- **SEO**: Next.js, Meta tags

## 🚀 Quick Start

```bash
git clone https://github.com/ashu-jha8797/portfolio.git
cd portfolio

npm install
npm run dev
```
